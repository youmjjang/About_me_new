나만의 기록

잠겨 있음

공개 소개는 누구나 볼 수 있어요. 이곳의 기록은 내 패스키로 들어온 뒤에만 열립니다.

비밀번호 없이 들어가기

기기에 저장한 패스키로 본인을 확인합니다.

처음이라면, 연습용 공간 만들기

새 계정에는 서로 다른 가상 기록 3개가 만들어집니다. 기존 계정에 패스키를 추가하려면 먼저 로그인하세요.

의 공간 아래 내용은 모두 가상 자료입니다.

내 패스키

기기를 잃어버려도 들어올 수 있도록 서로 독립적인 저장 위치에 두 개를 준비하세요.

두 번째 패스키 추가하기

같은 저장 위치에서 추가가 막히면 보안 키나 다른 기기·패스키 관리자를 선택하세요. 5분이 지났다면 다시 로그인해야 합니다.

기기를 잃어버렸다면

남아 있는 다른 패스키로 로그인하세요. 서버 목록에서 패스키를 삭제하면 해당 키로는 다시 들어올 수 없고, 모든 로그인도 종료됩니다.

마지막 패스키는 삭제할 수 없습니다. 기기와 동기화 계정까지 모두 잃어 사용 가능한 패스키가 0개라면 이 앱에서 계정을 복구할 수 없습니다. 새로 등록해도 기존 기록은 열리지 않습니다.

동기화형 패스키는 같은 관리자의 다른 기기에도 나타날 수 있습니다. 다른 기기에 보이는 같은 패스키를 두 개의 독립된 열쇠로 세지 마세요.

내 확인 기록

현재 탭에서 발생한 요청·응답과 내 공개키를 JSON으로 저장합니다. 쿠키·세션값은 기록하지 않습니다. 실제 개인정보는 입력하지 마세요.

공개 소개와 비공개 기록은 별도로 제공됩니다.

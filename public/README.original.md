# 김유미 | 포트폴리오

프로젝트와 경험, 문제 해결 과정을 정리한 개인 웹 포트폴리오입니다.

공개 페이지: https://youmjjang.github.io/About-me/

## 구성
- 자기소개와 프로젝트 바로가기
- NexusGuard Endpoint Agent: 팀 전체와 담당 모듈 범위 구분
- LogSentinel: 인증 로그 탐지·위험도·오류 해결
- Mini SOC: 실제 Nginx 로그 지속 감시·시간창 탐지·승인·대응 시뮬레이션·대시보드
- 대학 캡스톤: 도보 이동 시간 계산 앱 (화면 재구성 목업)
- File Integrity Monitor: 작은 보조 프로젝트 카드
- 기술 적용 맥락, 강점 탭, 경험 기록

## 실행
정적 HTML/CSS/JavaScript입니다. index.html을 브라우저에서 열거나 정적 서버로 확인합니다.

## 내용 기준
- 현재 공개 저장소 및 개발 기록 기준으로 작성했습니다.
- 기획 목표를 완료 성과로 표현하지 않습니다.
- Mini SOC 대응은 시뮬레이션이며, AI 보조 활용을 명시합니다.
- 파일 선택 이벤트와 실제 업로드 완료를 구분합니다.
- API 키, 개인 연락처, 팀원 이름, 비공개 문서 링크는 포함하지 않습니다.

## 수정
index.html: 내용 / styles.css: 디자인 / script.js: 접근성 강점 탭

## 화면 자료 (2026-09-15)
- NexusGuard: 원본 대시보드에 합성 테스트 이벤트 15건을 공급해 실제 규칙 엔진으로 처리한 화면. 운영 사고 수치가 아닙니다.
- LogSentinel / File Integrity Monitor: 샘플 입력으로 직접 실행한 화면.
- Mini SOC: 2026-09-15 Docker Nginx access.log 지속 감시에서 404 요청 → http_error → POST /alert 201 → 대시보드 반영 흐름을 직접 확인한 결과를 반영했습니다.
- 대학 캡스톤: 기존 설명을 토대로 image_gen으로 만든 앱 화면 재구성. 실제 원본 캡처가 아니며 지도·수치는 예시입니다.
- 이미지는 클릭해 확대할 수 있습니다. 학력·교육 전용 섹션은 제외했습니다.
